# ربط الموقع الإلكتروني

لو عندك موقع طلبات أونلاين (Turbo)، يتم ربطه بالكاشير لكل فرع بمفتاحين، واحد في كل اتجاه.

## المفتاحان

| | أين في نقطة البيع | أين في الموقع |
|---|---|---|
| **مفتاح API** (الموقع يرسل الطلبات للكاشير) | الإعدادات ← إدارة الفروع ← مفتاح الربط (API) ← «مفتاح API للموقع والفروع» | بيانات الفرع ← «مفتاح API لنقطة البيع» |
| **رمز التكامل** (الكاشير يبلغ الموقع بحالة الطلب) | نفس القسم ← «رمز التكامل من الموقع» | لوحة الموقع ← الطلبات ← «رمز التكامل» |

## خطوات الربط

<div class="steps">

1. في نقطة البيع افتح **الإعدادات ← إدارة الفروع ← مفتاح الربط (API)** واضغط **توليد مفتاح**. انسخ المفتاح.
2. في لوحة الموقع افتح بيانات الفرع والصق المفتاح في «مفتاح API لنقطة البيع»، وتأكد أن رابط الفرع هو عنوان نقطة البيع.
3. في لوحة الموقع أنشئ **رمز التكامل** (يظهر مرة واحدة فقط) وانسخه.
4. في نقطة البيع الصقه في **رمز التكامل من الموقع** واحفظ.
5. في **الإعدادات العامة** اكتب **رابط الموقع**.
6. اطلب من الدعم الفني تفعيل **طلبات الموقع** لو لم تكن مفعلة.

</div>

::: warning احتفظ بالمفتاحين سراً
أي شخص معه مفتاح API يستطيع إرسال طلبات لنقطة البيع. لو تسرّب، اضغط **توليد مفتاح** مرة أخرى وحدّثه في الموقع.
:::

## التأكد من الربط

- افتح الوردية وجرّب طلباً من الموقع: يجب أن يظهر في تبويب طلبات الموقع مع صوت.
- اضغط **قبول الطلب**: يجب أن تتغير حالته على الموقع.

## مشاكل شائعة

| المشكلة | الحل |
|---|---|
| الموقع يقول إن المحل مغلق | لا توجد وردية مفتوحة. افتح الوردية. |
| الطلبات لا تصل | المفتاح في الموقع لا يطابق مفتاح نقطة البيع. انسخه مرة أخرى. |
| «فشل في تحديث حالة الطلب» عند القبول | رابط الموقع خطأ، أو رمز التكامل لا يطابق، أو لا يوجد إنترنت. |
| منتج غير موجود | المنتج على الموقع غير مربوط بمنتج في نقطة البيع. أعد استيراده من لوحة الموقع. |
