# مرحباً بك في Turbo POS

هذا الدليل مكتوب لأصحاب المحلات والمديرين والكاشير. يشرح كل شاشة خطوة بخطوة بدون تفاصيل برمجية.

## النظام من ثلاث شاشات

| الشاشة | لمن | العنوان |
|---|---|---|
| **شاشة الكاشير** | الكاشير | تفتح بعد تسجيل الدخول: فتح الوردية، الطلبات، البيع المباشر، المصروفات |
| **لوحة الإدارة** | المدير وصاحب المحل | `/admin`: المنتجات، المخزون، المشتريات، التقارير، الإعدادات |
| **شاشة المطبخ** | المطبخ (للمطاعم والكافيهات) | `/kitchen`: الطلبات الجديدة ووقت التحضير |

## النظام يتشكل حسب نشاطك

عند التركيب يحدد الدعم الفني **نوع النشاط**: مطعم، كافيه، مخبز، ملابس وأحذية، سوبر ماركت، أو تجزئة عامة. على أساسه تظهر الشاشات المناسبة فقط:

- **المطعم والكافيه**: الصالة والطاولات، شاشة المطبخ، رسوم الخدمة، عدد الأفراد.
- **المحلات**: البيع المباشر بالباركود، المقاسات والألوان، المرتجع والاستبدال السريع.
- **التوصيل** و**طلبات الموقع** و**التصنيع** و**المتاجر المتعاونة** تُفعّل حسب الحاجة.

::: tip ملاحظة
إذا لم تجد شاشة مذكورة في هذا الدليل فغالباً هي غير مفعلة لنشاطك. تواصل مع الدعم الفني لتفعيلها.
:::

## مصطلحات سريعة

| الكلمة | معناها |
|---|---|
| **الوردية (الشيفت)** | فترة عمل الكاشير من فتح الوردية والأدراج إلى إغلاقها. كل المبيعات والمصروفات تُسجل عليها. |
| **الدرج (نقطة البيع)** | جهاز أو نقطة كاشير مستقلة داخل الوردية، لها نقدية افتتاحية ونقدية متوقعة وطابعة فواتير خاصة. |
| **البادج (Badge)** | كارت مطبوع بباركود فريد يمسحه الكاشير للدخول السريع لشاشة البيع أو تبديل الكاشير فوراً. |
| **نوع الطلب** | صالة، تيك أواي، توصيل، شركات، بيع مباشر... كل نوع له تبويب في شاشة الكاشير. |
| **الآجل** | طلب انتهى ولم يُدفع كاملاً، ويُحصّل لاحقاً من تبويب «تحصيل الآجل». |
| **المرتجع** | إرجاع صنف أو أكثر من فاتورة سابقة ورد المبلغ للعميل. |
| **الموديل** | منتج له مقاسات وألوان، وكل قطعة منه لها باركود. |
