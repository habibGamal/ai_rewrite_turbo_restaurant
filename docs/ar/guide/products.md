# المنتجات والفئات

## الفئات

**إدارة المنتجات ← الفئات**: كل فئة تظهر كزر في شاشة الكاشير (مثل مشروبات، سندوتشات، قمصان).

| الحقل | المعنى |
|---|---|
| اسم الفئة | يظهر على الزر. |
| التصنيف الرئيسي | لعمل فئات فرعية. |
| أنواع الطلبات المحظورة | أنواع طلبات لا تبيع هذه الفئة (مثلاً فئة لا تُوصّل). |
| محطة المطبخ / يظهر في شاشة المطبخ / وقت التحضير | للمطاعم. |

## أنواع المنتجات

| النوع | الاستخدام | أمثلة |
|---|---|---|
| **منتج استهلاكي** | يُشترى ويُباع كما هو، وله مخزون مباشر. | زجاجة مياه، قميص، علبة لبن |
| **منتج مُصنع** | يُباع للعميل ويتكون من مكونات تُخصم من المخزون عند البيع. | ساندوتش، عصير فريش |
| **مادة خام** | لا تُباع، تدخل في تصنيع المنتجات. | لحم، دقيق، سكر |

المنتج المُصنع والمادة الخام يظهران عند تفعيل **التصنيع**.

## إضافة منتج

| الحقل | المعنى |
|---|---|
| الاسم | كما يظهر على الزر والفاتورة. |
| الفئة | مكانه في شاشة الكاشير. |
| السعر | سعر البيع. |
| التكلفة | تكلفة الشراء أو التصنيع، لحساب الربح. |
| الوحدة | قطعة، كيلو، جرام، لتر... |
| الباركود | للمسح في الكاشير. يمكن أكثر من باركود لنفس المنتج. |
| الحد الأدنى للمخزون | للتنبيه في تقرير المخزون. |
| الطابعات / الطابعة | الطابعة التي تُطبع عليها تذكرة الصنف. |
| مخزن السحب | المخزن الذي يُخصم منه عند البيع. |
| غير نشط | لإخفائه من الكاشير بدون حذفه. |

**المكونات** (للمنتج المُصنع): اختر المواد الخام والكمية لكل وحدة. عند بيع المنتج تُخصم المكونات من المخزون تلقائياً.

## رفع المنتجات من ملف Excel

**إدارة النظام ← رفع ملف Excel**: لإضافة عدد كبير من المنتجات والفئات مرة واحدة.

## الأصناف بالوزن

ضع **بادئة باركود الميزان** في الإعدادات كما هي في ميزانك (الافتراضي 23). عند مسح ملصق الميزان يقرأ النظام الصنف والوزن تلقائياً. الأصناف بالوزن لا تكون موديلات بمقاسات.
