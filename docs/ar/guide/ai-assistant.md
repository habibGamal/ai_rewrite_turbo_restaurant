# المساعد الذكي

**المساعد الذكي** يربط تطبيقات الذكاء الاصطناعي (ChatGPT وClaude وGemini) ببيانات متجرك، فتسأله بلغتك عن المبيعات والأصناف والورديات والمخزون ويجيب من أرقامك الحقيقية. مثال: «ما أكثر الأصناف ربحاً هذا الشهر؟» أو «لماذا انخفضت مبيعات يوم الجمعة؟».

- **للقراءة فقط**: لا يستطيع المساعد تعديل أي شيء أو حذفه.
- **حسب الصلاحيات**: يرى كل مستخدم من البيانات ما تسمح به صلاحياته في التقارير فقط.
- **يحمي البيانات الحساسة**: كلمات المرور والإعدادات غير متاحة له، وأرقام هواتف العملاء تظهر مخفية جزئياً إلا لمن يملك صلاحية عرض العملاء.

## التفعيل

<div class="steps">

1. يفعّل الدعم الفني ميزة **«المساعد الذكي»**.
2. يعطي المدير صلاحية **«استخدام المساعد الذكي»** لمن يريد من [الأدوار](/ar/guide/users).
3. تظهر للمستخدم صفحة **إدارة النظام ← المساعد الذكي**، وفيها **رابط الخادم** وزر لنسخه. الرابط ينتهي بـ `/mcp/pos`، مثل `https://اسم-متجرك/mcp/pos`.

</div>

## طريقة الربط

::: warning قبل البدء
سجّل الدخول بالبريد الإلكتروني وكلمة المرور. الدخول بالبادج لا يكفي للربط.
:::

### ChatGPT

<div class="steps">

1. **الإعدادات ← التطبيقات والموصلات**، ثم فعّل **وضع المطوّر**.
2. أنشئ موصلاً جديداً والصق رابط الخادم، واختر المصادقة **OAuth** واترك باقي الحقول فارغة.
3. سجّل الدخول ببريدك وكلمة المرور في صفحة المتجر، ثم اضغط **«موافقة»**.

</div>

### Claude

<div class="steps">

1. **الإعدادات ← الموصلات**، ثم **«إضافة موصل مخصص»**.
2. الصق رابط الخادم واضغط **«إضافة»**، ثم **«اتصال»**.
3. سجّل الدخول ثم اضغط **«موافقة»**.

</div>

### Gemini

<div class="steps">

1. **الإعدادات ← التطبيقات المتصلة**، ثم إضافة خادم MCP.
2. الصق رابط الخادم، واترك معرّف العميل وكلمة سره فارغين.
3. سجّل الدخول ثم اضغط **«موافقة»**.

</div>

### Claude Code (للمطورين)

```bash
claude mcp add --transport http pos https://اسم-متجرك/mcp/pos
```

ثم اكتب `/mcp` في الجلسة واختر المصادقة.

## ماذا يستطيع المساعد؟

يقرأ المساعد البيانات نفسها التي تعرضها التقارير: المبيعات وتفصيلها، والأصناف وأداؤها، والطلبات، والورديات والعجز والزيادة، والمصروفات والإيرادات، والعملاء، والمرتجعات، وأداء الموظفين، وسجل التعديلات، والمخزون وحركاته، والمشتريات والموردين، والمطبخ والتوصيل وطلبات الموقع، والمعدات والرسوم والتصنيع، حسب المفعّل في متجرك.

ويأتي معه **قوالب تحليل جاهزة** تختارها من التطبيق:

| القالب | ماذا يعطيك |
|---|---|
| Daily briefing | ملخص يوم (أمس افتراضياً) مقارنة باليوم السابق ونفس اليوم من الأسبوع الماضي، وأهم الأصناف، وفروق النقدية، والأصناف التي قاربت على النفاد. |
| Month review | مراجعة شهر مقارنة بالشهر السابق ونفس الشهر من العام الماضي، وأسباب التغير. |
| Menu engineering | تصنيف الأصناف حسب الكمية والربح داخل كل فئة، وماذا تفعل مع كل مجموعة. |
| Cash reconciliation | الورديات التي فيها عجز أو زيادة، ومن فتحها، والأنماط حسب الكاشير أو منفذ البيع. |
| Loss prevention | علامات التسرّب: الإلغاءات، والأصناف المحذوفة بعد الطباعة، والخصومات الكبيرة، والمرتجعات، والتالف وفروق الجرد. |
| Inventory health | الأصناف القريبة من النفاد، والراكدة، وفروق الجرد، والتالف حسب السبب، وزيادات تكلفة الشراء. |
| Customer retention | العملاء الجدد والعائدون، وأفضل العملاء، والعملاء المعتادون الذين توقفوا عن الطلب. |
| Staffing by hour | ساعات وأيام الذروة والهدوء لتخطيط الموظفين والورديات. |

## الاستعلامات المباشرة

ميزة إضافية يفعّلها الدعم الفني (**«الاستعلامات المباشرة للمساعد الذكي»**)، للأسئلة التي لا تغطيها الأدوات الجاهزة. تتيح للمساعد قراءة البيانات باستعلامات مباشرة على جداول مخصصة له:

- تظهر **للمدير والدعم الفني فقط**.
- للقراءة فقط، ولا تصل إلى المستخدمين أو كلمات المرور أو الإعدادات أو أرقام الهواتف.
- لكل استعلام حد زمني قدره 5 ثوانٍ وحد أقصى قدره 500 صف.
- يُسجَّل كل استعلام في سجل المساعد الذكي.

## التطبيقات المتصلة وإلغاء الربط

في صفحة **المساعد الذكي** جدول **«التطبيقات المتصلة»**: التطبيق، والمستخدم (يراه المدير لكل المستخدمين)، وآخر تجديد، وآخر استخدام. يبقى الربط ثلاثين يوماً من آخر استخدام. اضغط **«إلغاء الربط»** ليتوقف التطبيق فوراً عن قراءة بيانات المتجر، ويلزم ربطه من جديد لاستخدامه.

## سجل المساعد الذكي

**إدارة النظام ← سجل المساعد الذكي**: كل سؤال وصل إلى بيانات المتجر، ومن المستخدم والتطبيق، ووقته. يُحتفظ بالسجل 180 يوماً.

## مشكلات شائعة

| المشكلة | الحل |
|---|---|
| رسالة «ميزة المساعد الذكي غير مفعلة حالياً» | تواصل مع الدعم الفني لتفعيلها. |
| رسالة «لا تملك صلاحية استخدام المساعد الذكي» | اطلب من المدير منحك الصلاحية. |
| المساعد يقول إنه لا يستطيع رؤية تقرير معين | ليس لديك صلاحية هذا التقرير، أو الجزء غير مفعل في متجرك. |
| توقف التطبيق عن الإجابة من بيانات المتجر | ربما أُلغي الربط أو مرت ثلاثون يوماً بلا استخدام. أعد الربط بالخطوات أعلاه. |
