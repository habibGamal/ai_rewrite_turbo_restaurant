# شاشة الكاشير وأنواع الطلبات

## شكل الشاشة

أعلى الشاشة (أو جانبها) **تبويبات**، كل تبويب نوع طلب أو قائمة:

| التبويب | الاستخدام |
|---|---|
| **صالة** | طلبات الطاولات (للمطاعم والكافيهات). |
| **تيك أواي** | طلب سريع على الكاونتر. |
| **توصيل** | طلب لعميل بعنوان مع سائق ومنطقة. |
| **شركات** | طلبات الشركات والعملاء بالحساب. |
| **طلبات** (Talabat) | طلبات تطبيقات التوصيل. |
| **بيع مباشر** | امسح وادفع، للمحلات. شرحه في [البيع المباشر](/ar/guide/instant-sale). |
| **طلبات الموقع** | الطلبات الواردة من الموقع. شرحها في [طلبات الموقع](/ar/guide/web-orders). |
| **تحصيل الآجل** | الطلبات المنتهية التي لم تُدفع كاملاً. |
| **مصاريف** | تسجيل مصروف على الوردية. |
| **منتهي** / **ملغي** | طلبات الوردية المنتهية والملغاة. |

الأسماء والألوان والترتيب يحددها المدير من [أنواع الطلبات](/ar/guide/order-types) و«تبويبات الكاشير» في الإعدادات.

## إنشاء طلب (صالة، تيك أواي، توصيل، شركات)

<div class="steps">

1. ادخل على التبويب واضغط **إنشاء طلب**. في الصالة اختر الطاولة. لو نوع الطلب يسأل عن **عدد الأفراد** تظهر نافذة لإدخاله.
2. تفتح شاشة **إدارة الطلب**: الفئات والمنتجات على جانب، والأصناف المختارة والإجمالي على الجانب الآخر.
3. اضغط المنتجات لإضافتها، أو امسح الباركود. لتعديل الكمية أو كتابة ملاحظة للمطبخ اضغط على الصنف.
4. اضغط **حفظ**. في المطعم تختار **حفظ وطباعة في المطبخ** فيصل الطلب لشاشة المطبخ وتُطبع تذكرته، أو **حفظ فقط**.
5. عند الحساب اضغط **إنهاء الطلب**، اختر طريقة الدفع، ثم **طباعة الفاتورة**.

</div>

## أزرار شاشة إدارة الطلب

| الزر | الوظيفة |
|---|---|
| **بيانات العميل** | اختيار أو إضافة عميل بالاسم ورقم التليفون. مطلوب للتوصيل وللآجل. |
| **بيانات السائق** | اختيار السائق لطلب التوصيل. |
| **خصم الطلب** | خصم بنسبة أو مبلغ على الطلب كله (بالصلاحية). |
| **ملاحظات الطلب** | ملاحظة عامة على الطلب. |
| **تغيير الطلب الى** | نقل الطلب لنوع آخر (مثلاً من صالة إلى تيك أواي). |
| **رسوم إضافية** | إضافة رسم بأي اسم ومبلغ. [التفاصيل](/ar/guide/fees). |
| **إضافة معدات** | شيشة، بلايستيشن، أو أي معدة بسعر ثابت. [التفاصيل](/ar/guide/equipment). |
| **عدد الأفراد** | تعديل عدد أفراد الطلب. [التفاصيل](/ar/guide/guests). |
| **طباعة في المطبخ** | إعادة طباعة التذكرة كلها أو تغييرات الطلب فقط. |
| **إلغاء** | إلغاء الطلب (بالصلاحية). |

## الحسابات على الشاشة

| السطر | المعنى |
|---|---|
| **المجموع** | مجموع الأصناف. |
| **الخصم** | خصومات الأصناف والطلب. |
| **الخدمة** | رسوم الخدمة (للصالة) أو رسوم التوصيل. تُحسب على الأصناف فقط. |
| **الضريبة** | إن وجدت. |
| **رسوم إضافية / المعدات** | تُضاف للإجمالي. |
| **الإجمالي** | المطلوب من العميل. |

## المنتجات بالوزن

امسح ملصق الميزان. النظام يقرأ الصنف والوزن (أو السعر) من الباركود حسب **بادئة باركود الميزان** في الإعدادات.

## المنتجات ذات المقاسات والألوان

لو المنتج له موديل، الضغط عليه يفتح نافذة لاختيار المقاس واللون. أو امسح باركود القطعة مباشرة. [التفاصيل](/ar/guide/variants).
