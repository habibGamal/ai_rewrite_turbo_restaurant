# المستخدمون والصلاحيات

## إضافة مستخدم

**لوحة الإدارة ← المستخدمين ← إضافة**: الاسم، البريد، كلمة المرور، الدور، و**رمز PIN للبادج** (4 أرقام، مطلوب للمديرين لتأكيد هويتهم عند الدخول بالبادج).

## تسجيل الدخول السريع بالبادج (Badge Quick Login)

يتيح النظام طباعة كارت (بادج) لكل كاشير وموظف لتسجيل الدخول الفوري دون كتابة بيانات الدخول:

- **طباعة البادج**: من صفحة المستخدم، اضغط **«طباعة بادج»** لإنشاء كارت يحتوي على باركود عشوائي فريد من 16 رقماً (Code 128). يُعرض الكارت للطباعة لمرة واحدة فقط حفاظاً على الأمان، ولا يُحفظ في النظام سوى تجزئة مشفرة (Hash).
- **إعادة الإصدار والإلغاء**: الضغط على «طباعة بادج» مرة أخرى يستبدل الكود القديم فوراً، وزر **«إلغاء البادج»** يسحب البادج ويعطله.
- **تسجيل الدخول من شاشة البادج (`/badge`)**: في صفحة تسجيل الدخول، اضغط «دخول نقطة البيع بالبادج» ثم امسح البادج بقارئ الباركود، فيفتح النظام شاشة الكاشير فوراً.
- **رمز PIN للأدوار الإدارية**: المستخدمون الذين يحق لهم دخول لوحة الإدارة يطلب منهم النظام إدخال رمز PIN مكون من 4 أرقام بعد مسح البادج.
- **عزل جلسة البادج (POS-only)**: الجلسة المفتوحة بالبادج مخصصة لنقطة البيع فقط، وأي محاولة لدخول لوحة الإدارة تحول المستخدم تلقائياً لنقطة البيع حتى يقوم بتسجيل دخول كامل بكلمة المرور.
- **تبديل الكاشير من شاشة البيع**: عند انتهاء وردية كاشير، يمسح موظف آخر بادجه عبر «تبديل الكاشير» ليتبدل الحساب ويستلم منفذ البيع.
- **حماية ضد التخمين**: يُحسب عدد محاولات رمز PIN الخاطئة لكل مستخدم: بعد 5 محاولات خاطئة يُقفل الدخول بالبادج لهذا المستخدم 15 دقيقة، ومسح بادج آخر لا يعيد العداد إلى الصفر. ويُحد كذلك عدد المحاولات من كل جهاز.
- **صفحة الملف الشخصي**: لا يمكن فتح صفحة الملف الشخصي أو تغيير كلمة المرور من جلسة البادج.

## الأدوار الجاهزة

| الدور | الصلاحيات |
|---|---|
| **مدير (admin)** | كل شيء في النظام. |
| **كاشير (cashier)** | فتح وإغلاق الوردية ومنفذ البيع، تسجيل الدخول بالبادج، إنشاء الطلبات ومحاسبتها، المرتجع، المصروفات، العملاء، طباعة الفاتورة، فتح درج النقود. |
| **مطبخ (kitchen)** | شاشة المطبخ فقط. |
| **مشاهد (viewer)** | لوحة الإدارة وكل التقارير بدون تعديل. |
| **مراقب (watcher)** | الطلبات والعملاء والمخزون وأهم التقارير. |

## تعديل الصلاحيات

**إدارة النظام ← الأدوار والصلاحيات**: افتح الدور وفعّل أو ألغِ أي صلاحية. أمثلة مهمة للكاشير:

| الصلاحية | متى تعطيها |
|---|---|
| الدخول لنقطة البيع بالبادج (`user.badge_login`) | للسماح بتسجيل الدخول بمسح كارت البادج. |
| فتح واستلام منفذ البيع (`terminal.open`) | لفتح منفذ بيع أو استلام منفذ كاشير آخر. |
| إغلاق منفذ البيع الخاص به (`terminal.close`) | لإغلاق منفذه عند انتهاء عمله. |
| إغلاق منفذ بيع كاشير آخر نيابةً عنه (`terminal.close_others`) | للمشرف، لإغلاق منفذ مفتوح لموظف غير موجود. |
| ربط الأجهزة بمنافذ البيع (`terminal.bind_device`) | للمدير، لربط متصفح الجهاز بمنفذ بيع. |
| إلغاء الطلبات | لو تثق في الكاشير بإلغاء طلب محفوظ. |
| تطبيق خصم على الطلبات والأصناف | لو مسموح له بالخصم. |
| تعديل وحذف الأصناف بعد حفظ الطلب | لو مسموح له بتعديل طلب بعد إرساله. |
| مرتجع تالف (بدون إرجاع للمخزن) | لو يقرر بنفسه أن القطعة تالفة. |
| مرتجع طلبات أقدم من الحد المسموح | للمشرف فقط عادةً. |
| حذف رسوم إضافية / تقليل معدات | للمدير عادةً. |
| طباعة ملصقات الباركود | لمن يطبع الملصقات من المنتجات والمستندات. [التفاصيل](/ar/guide/labels). |
| تعديل مصروفات وإيرادات الورديات المغلقة | للمدير، وتحتاج تفعيل الميزة من الدعم الفني. |
| استخدام المساعد الذكي | لمن تسمح له بربط ChatGPT أو Claude أو Gemini ببيانات المتجر. [التفاصيل](/ar/guide/ai-assistant). |

### صلاحيات التبويبات

كل تبويب في شاشة الكاشير له صلاحية مستقلة باسم «تبويب: ...». مثلاً يمكنك إخفاء تبويب «توصيل» أو «مصاريف» عن كاشير معين.

::: tip
الصلاحيات الخاصة بأجزاء أو مميزات غير مفعلة عندك (مثل الدفع الآجل والمرتجعات) لا تظهر في الشاشة أصلاً، ولا تعمل حتى لو كانت ممنوحة.
:::
