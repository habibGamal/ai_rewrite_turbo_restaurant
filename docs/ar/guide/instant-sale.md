# البيع المباشر (الباركود)

تبويب **«بيع مباشر»** مصمم للمحلات: امسح القطع وادفع في خطوة واحدة، بدون فتح طلب وحفظه. الفاتورة تُسجّل وتُدفع وتنتهي مرة واحدة.

## خطوات البيع

<div class="steps">

1. امسح باركود القطعة، أو اكتب الكود واضغط Enter، أو اختر من الفئات.
2. لتكرار نفس القطعة اكتب الكمية ثم `*` ثم الكود. مثال: `3*12345` تعني 3 قطع.
3. عدّل الكميات بأزرار <kbd>+</kbd> و <kbd>-</kbd> أو احذف السطر بـ <kbd>Del</kbd>.
4. اضغط **دفع** (<kbd>F12</kbd>)، أو <kbd>Space</kbd> وخانة المسح فارغة.
5. اختر طريقة الدفع (نقدي، فيزا، أو أكثر من طريقة) وأكد. تُطبع الفاتورة.

</div>

## اختصارات لوحة المفاتيح

| المفتاح | الوظيفة |
|---|---|
| <kbd>F2</kbd> | الذهاب لخانة المسح / البحث |
| <kbd>F4</kbd> | خصم |
| <kbd>F6</kbd> | بيانات العميل |
| <kbd>F8</kbd> | تعليق البيع |
| <kbd>F9</kbd> | الفواتير المعلقة |
| <kbd>F10</kbd> | مرتجع / استبدال |
| <kbd>F12</kbd> | دفع |
| <kbd>Esc</kbd> | مسح السلة |
| <kbd>↑</kbd> <kbd>↓</kbd> | التنقل بين الأصناف |
| <kbd>+</kbd> <kbd>-</kbd> | زيادة / تقليل كمية الصنف المحدد |
| <kbd>Del</kbd> | حذف الصنف المحدد |

## تعليق البيع

العميل نسي شيئاً أو يريد أن يفكر؟ اضغط **تعليق البيع** (<kbd>F8</kbd>). السلة تُحفظ وتستطيع خدمة عميل آخر. من **الفواتير المعلقة** (<kbd>F9</kbd>) تسترجعها في أي وقت.

::: warning
الفواتير المعلقة تُحذف عند إغلاق الوردية لأنها لم تصبح مبيعات.
:::

## إعادة طباعة آخر فاتورة

زر **إعادة طباعة آخر فاتورة** يطبع آخر فاتورة تمت من نفس الشاشة.

## شاشة العميل

لو عندك شاشة ثانية مواجهة للعميل، افتح **شاشة العميل** عليها ليرى الأصناف والإجمالي أثناء المسح.

## ملاحظات

- البيع المباشر لا يرسل شيئاً للمطبخ.
- لا تُضاف عليه رسوم إضافية أو معدات أو عدد أفراد.
- المرتجع والاستبدال من نفس الشاشة: [المرتجعات والاستبدال](/ar/guide/returns).
