# المخزون والمشتريات

## المخازن

**إدارة المخزون ← المخازن**: عرّف مخازنك (مخزن رئيسي، مطبخ، بار...) وحدد **المخزن الافتراضي**. كل منتج له **مخزن السحب** الذي يُخصم منه عند البيع.

## المشتريات

**المشتريات ← فواتير الشراء**: سجّل فاتورة المورد بالأصناف والكميات وسعر الوحدة. عند تأكيدها تزيد الكميات في المخزن وتتحدث التكلفة.

**المشتريات ← مرتجع المشتريات**: إرجاع أصناف للمورد.

**إدارة المبيعات ← الموردين**: بيانات الموردين.

### طريقة حساب التكلفة

من **الإعدادات ← إدارة المشتريات**:

| الطريقة | المعنى |
|---|---|
| إيقاف | التكلفة لا تتغير تلقائياً. |
| فوري (آخر سعر) | تكلفة المنتج = آخر سعر شراء. |
| متوسط مرجح | تكلفة المنتج = متوسط الكميات الموجودة بأسعارها. |

## حركات المخزون

| الشاشة | الاستخدام |
|---|---|
| **أذون التحويل** | نقل كمية من مخزن لمخزن. |
| **أذون الصرف** | صرف كمية لاستخدام داخلي. |
| **التالف (الهالك)** | تسجيل ما فسد أو انكسر، مع إمكانية تحديد **سبب الهالك** لكل صنف (منتهي الصلاحية، تالف، تلف تخزين، هالك تحضير، خطأ تحضير/طلب، أخرى). يُخصم من المخزون ويظهر في تبويب الهالك بتقرير حركة المخزون. |
| **الجرد** | عدّ المخزن فعلياً. النظام يحسب الفرق بين المسجل والفعلي ويعدّل الرصيد عند التأكيد. |
| **أوامر التصنيع** | تصنيع كمية مسبقاً من منتج مُصنع (مثل عجين أو صوص) وخصم مكوناتها. |
| **وصفات التصنيع** | الوصفة الثابتة لأمر التصنيع. |

## البيع والمخزون

- بيع منتج استهلاكي يخصمه من مخزن السحب.
- بيع منتج مُصنع يخصم مكوناته.
- المرتجع «يرجع للمخزن» يعيد الكمية، و«تالف» لا يعيدها.

## التقارير

- **تقرير حركة المخزون**: التقرير الموحد لجميع الحركات والهالك (بحسب الأسباب) والمشتريات والمخازن والتنبيهات.
- **تقرير المخزون**: الأرصدة الحالية وقيمتها.
- **كشف حركة صنف**: السجل الكامل لحركات صنف معين.
- **سجل تغيير التكلفة**: تاريخ تعديل أسعار التكلفة.
