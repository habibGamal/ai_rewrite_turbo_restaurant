# أنواع الطلبات

**إدارة المبيعات ← أنواع الطلبات**. كل نوع طلب يظهر كتبويب في شاشة الكاشير. يمكنك تعديل الموجود أو إضافة نوع جديد (مثلاً «حجوزات» أو «طلبات تليفون»).

## الحقول

| الحقل | المعنى |
|---|---|
| **الاسم** | اسم التبويب. |
| **الكود** | معرّف ثابت بحروف إنجليزية صغيرة (مثل `phone_orders`). |
| **السلوك** | كيف يعمل الطلب: صالة بطاولات، كاونتر، توصيل، شركات، بيع مباشر... |
| **اللون** و**الأيقونة** | شكل التبويب. |
| **تصميم الشبكة** | للصالة: رسم الطاولات وأماكنها بمصمم الصالة. |
| **نشط** | إظهار أو إخفاء التبويب. |
| **السماح بالإغلاق والدفع لاحقاً** | إنهاء الطلب بدون دفع وتسجيله آجلاً. |
| **السماح بالدفع الجزئي** | دفع جزء والباقي آجل. |
| **يتطلب ربط عميل** | لا آجل ولا دفع جزئي بدون عميل. |
| **عدد الأفراد** | لا يُطلب / اختياري / إجباري. [التفاصيل](/guide/guests). |

الأنواع **النظامية** (الأساسية) لا تُحذف، لكن يمكن إيقافها وتغيير اسمها.

## مصمم الصالة

للمطاعم والكافيهات: من نوع «صالة» افتح **تصميم الشبكة**، واسحب الطاولات لأماكنها كما في المكان الحقيقي. الكاشير يرى نفس الرسم ويختار الطاولة منه، مع لون للطاولات **المشغولة** و**المتاحة**.

**إدارة المطعم ← أنواع الطاولات**: لتعريف أشكال وأحجام الطاولات.

## ترتيب التبويبات

**الإعدادات ← تبويبات الكاشير**: ترتيب التبويبات، إظهارها أو إخفاؤها، وعرضها أفقياً أعلى الشاشة أو عمودياً جانبها.
