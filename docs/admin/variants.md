# المقاسات والألوان (الموديلات)

ميزة تُفعّل من الدعم الفني، مناسبة لمحلات الملابس والأحذية وأي منتج له أشكال متعددة.

## الفكرة

- **الموديل**: المنتج الأساسي، مثل «قميص كتان».
- **المحاور**: ما يتغير في الموديل، مثل المقاس واللون والقصّة. تضيف أي عدد من المحاور.
- **المتغيرات (القطع)**: كل تركيبة مثل «قميص كتان / L / أزرق». لكل قطعة **كود صنف (SKU)** و**باركود** ومخزون خاص.
- **السعر** واحد على الموديل، ويمكن تحديد **سعر خاص** لقطعة معينة.

## إنشاء موديل

<div class="steps">

1. **إدارة المنتجات ← الموديلات ← إضافة**: اكتب **اسم الموديل**، **الفئة**، **الماركة**، **سعر البيع**، **التكلفة المبدئية**، **الوحدة**، و**بادئة كود الصنف (SKU)**.
2. أضف المحاور: **اسم المحور** (مثلاً «المقاس») و**القيم** (S، M، L، XL). للون يمكن تحديد اللون نفسه ليظهر كدائرة ملونة.
3. اضغط **توليد المتغيرات**. ينشئ النظام كل التركيبات (حتى 500 مرة واحدة) مع كود وباركود لكل قطعة.
4. راجع القطع: عدّل الباركود أو اضغط **تحديد سعر خاص** لقطعة. **إلغاء السعر الخاص** يرجعها لسعر الموديل.
5. اضغط **طباعة ملصقات** لطباعة ملصقات القطع بالعدد المطلوب، بأحد [تصميمات الملصقات](/guide/labels). يظهر الزر عند تفعيل طباعة الملصقات.

</div>

::: tip تغيير السعر
تغيير سعر الموديل يغيّر سعر كل القطع التي ليس لها سعر خاص.
:::

## مصفوفة المخزون

من صفحة الموديل، **مصفوفة المخزون** تعرض كمية كل مقاس ولون في جدول واحد.

## البيع

- **امسح باركود القطعة**: تُضاف مباشرة بمقاسها ولونها.
- أو اضغط على الموديل في الكاشير: تظهر نافذة لاختيار المقاس واللون.
- القطعة **الموقوفة** (غير نشطة) لا تظهر ولا تُباع.
- لو أضفت قطعة بمقاس خطأ في البيع المباشر، اضغط **تغيير المقاس / اللون** على السطر بدل حذفه.
