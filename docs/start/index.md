# مرحباً بك في Turbo POS

هذا الدليل مكتوب لأصحاب المحلات والمديرين والكاشير. يشرح كل شاشة خطوة بخطوة بدون تفاصيل برمجية.

## النظام من ثلاث شاشات

| الشاشة | لمن | العنوان |
|---|---|---|
| **شاشة الكاشير** | الكاشير | تفتح بعد تسجيل الدخول: فتح الوردية، الطلبات، البيع المباشر، المصروفات |
| **لوحة الإدارة** | المدير وصاحب المحل | `/admin`: المنتجات، المخزون، المشتريات، التقارير، الإعدادات |
| **شاشة المطبخ** | المطبخ (للمطاعم والكافيهات) | `/kitchen`: الطلبات الجديدة ووقت التحضير |

## النظام يتشكل حسب نشاطك

عند التركيب يحدد الدعم الفني **نوع النشاط**: مطعم، كافيه، مخبز، ملابس وأحذية، سوبر ماركت، أو تجزئة عامة. على أساسه تظهر الشاشات المناسبة فقط:

- **المطعم والكافيه**: الصالة والطاولات، شاشة المطبخ، رسوم الخدمة، عدد الأفراد.
- **المحلات**: البيع المباشر بالباركود، المقاسات والألوان، المرتجع والاستبدال السريع.
- **التوصيل** و**طلبات الموقع** و**التصنيع** و**المتاجر المتعاونة** تُفعّل حسب الحاجة.
- مميزات إضافية يفعّلها الدعم الفني لأي نشاط: الدفع الآجل، المرتجعات، منافذ البيع المتعددة، توليد الباركود وطباعة الملصقات، [المساعد الذكي](/admin/ai-assistant)، وغيرها.

::: tip نصيحة
إذا لم تجد شاشة مذكورة في هذا الدليل فغالباً هي غير مفعلة لنشاطك. تواصل مع الدعم الفني لتفعيلها.
:::

## أبرز مميزات النظام

- **نقطة البيع**: تبويبات لأنواع الطلبات، البيع المباشر بالباركود والميزان، الفواتير المعلقة، صالة وطاولات المطعم، التوصيل، الدفع المقسّم والآجل، الرسوم الإضافية، والمعدات.
- **الورديات والنقدية**: النقدية الافتتاحية، متابعة النقدية المتوقعة، تعدد منافذ البيع وتسليم الكاشير، المصروفات، الإيرادات الأخرى، المرتجعات، وسجل الرقابة.
- **المطبخ والطباعة**: شاشة مطبخ حية، توجيه التذاكر حسب المحطة، طباعة الفواتير الحرارية، البحث عن طابعات الشبكة، وتصميم وطباعة ملصقات الباركود عبر برنامج Turbo Label.
- **المخزون والمشتريات**: مواد خام ومنتجات استهلاكية ومصنّعة بوصفات، تعدد المخازن، طرق حساب التكلفة، فواتير الشراء ومرتجعاتها، التالف، الجرد، التحويلات وأذون الصرف.
- **الربط والمزامنة**: استقبال طلبات موقع الطلبات الإلكتروني وتحديث حالاتها، مزامنة الفروع، والمزامنة مع المنصة المركزية.
- **الإدارة والتقارير**: صلاحيات مفصلة حسب الدور، تقارير مالية ومخزنية قابلة للتصدير إلى Excel، وربط المساعد الذكي للقراءة والتحليل.
