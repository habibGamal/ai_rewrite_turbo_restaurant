# ربط المساعد الذكي (MCP)

يتيح لك هذا التكامل ربط تطبيقات الذكاء الاصطناعي ببيانات متجرك للقراءة والتحليل فقط عبر رابط آمن ينتهي بـ `/mcp/pos`.

::: warning تنبيه
الميزة مخفية افتراضياً ويتم تفعيلها من **الدعم الفني** أولاً، ثم يمنح المدير صلاحية **استخدام المساعد الذكي** من [المستخدمون والصلاحيات](/admin/users).
:::

## قبل البدء

- تأكد من أن النظام يعمل عبر رابط HTTPS عام يمكن الوصول إليه من الإنترنت.
- سجّل الدخول بالبريد الإلكتروني وكلمة المرور؛ الدخول بالبادج لا يكفي لاعتماد الربط.
- انسخ **رابط الخادم** من <span class="path">لوحة الإدارة › إدارة النظام › المساعد الذكي</span>.

## خطوات الربط

<div class="steps">

1. في ChatGPT افتح **الإعدادات ← التطبيقات والموصلات** وفعّل وضع المطوّر، أو في Claude افتح **الإعدادات ← الموصلات ← إضافة موصل مخصص**، أو في Gemini افتح **الإعدادات ← التطبيقات المتصلة ← إضافة خادم MCP**.
2. الصق رابط الخادم (`https://اسم-متجرك/mcp/pos`) واختر المصادقة **OAuth** مع ترك الحقول الاختيارية فارغة.
3. سجّل الدخول بحسابك في المتجر واضغط **موافقة**.

</div>

## إدارة التطبيقات المتصلة

من صفحة **المساعد الذكي** يمكنك مراجعة التطبيقات المربوطة وآخر استخدام لكل منها، والضغط على **إلغاء الربط** لإيقاف أي تطبيق فوراً. كما يسجّل النظام كل استعلام في <span class="path">إدارة النظام › سجل المساعد الذكي</span> لمدة 180 يوماً.

لمعرفة التقارير والقوالب المتاحة راجع صفحة [المساعد الذكي](/admin/ai-assistant). ولتفاصيل المطورين ووضع الاستعلامات المباشرة راجع قسم المطورين (`ai-mcp`).
