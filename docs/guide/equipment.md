# المعدات

ميزة تُفعّل من الدعم الفني. مناسبة للكافيهات وأماكن الترفيه: شيشة، بلايستيشن، طاولة بلياردو، أو أي شيء يُؤجر على الطلب بسعر ثابت.

## تعريف المعدات

**إدارة المبيعات ← المعدات ← إضافة**:

| الحقل | المعنى |
|---|---|
| الاسم | اسم المعدة. |
| سعر الاستخدام | ما يدفعه العميل في كل مرة. |
| تكلفة الاستخدام | تكلفتها عليك (فحم، كهرباء...). تُخصم من الربح. |
| أنواع الطلبات المسموح بها | أين تظهر المعدة (مثلاً الصالة فقط). |
| نشط | لإخفائها مؤقتاً. |

## إضافة معدة على طلب

<div class="steps">

1. في إدارة الطلب اضغط **إضافة معدات**.
2. ابحث عن المعدة واختر العدد.
3. احفظ. يظهر **إجمالي المعدات** ويُضاف للإجمالي.

</div>

- تقليل العدد أو حذف معدة بعد الحفظ يحتاج صلاحية «حذف أو تقليل معدات من الطلب» ويُسجل.
- لو غيّرت نوع الطلب لنوع غير مسموح له بالمعدة، يرفض النظام التغيير.

## التقرير

**التقارير ← تقرير المعدات**: عدد مرات الاستخدام، الإيراد، التكلفة، الربح، والمردود لكل معدة.
