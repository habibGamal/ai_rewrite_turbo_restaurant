# Issue Tracker

Tracking lives in local Markdown under `.workspace/specs/`:

- Feature spec: `.workspace/specs/<feature>/spec.md`
- Issue tickets: `.workspace/specs/<feature>/issues/NN-slug.md`
- Wayfinder maps: `.workspace/specs/<effort>/map.md`

When a spec ships, move its lasting facts into `docs/` in the same PR and move the spec folder into `.workspace/archive/`.
